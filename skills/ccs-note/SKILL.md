# /ccs-note — 이 세션의 인수인계 메모

이 세션에서 실제로 한 일만으로 아래 양식을 채워 `ccs note` 에 넘긴다. 새로 조사하거나 파일을 더 읽지 않는다 — 이미 아는 맥락으로 쓴다(필요하면 `git status` 한 번 정도만).

```bash
ccs note <<'EOF'
# <이 세션의 목표 한 줄 — 처음 보는 사람도 알아들을 말로>
상태: 진행 중 | 대기: <무엇을 · 누구를 기다리는지> | 끝남
## 지금 상태
- 된 것, 안 된 것. 커밋·푸시·MR 여부
## 다음에 열면 할 것
- 가장 먼저 할 일 한 줄 (첫 줄이 목록에 보인다)
## 주의 · 실패한 시도
- 다시 하면 안 되는 것, 막혔던 이유
## 관련 파일 · 명령
- 경로, 브랜치, 띄워 둔 서버, 확인 명령
EOF
```

`ccs` 가 PATH 에 없으면 `python3 <이 스킬 폴더>/../../ccs.py note` 로 부른다.

## 규칙

- **상태는 셋 중 하나.** 사용자의 답·외부 회신·리뷰를 기다리면 `대기: …` 에 무엇을 기다리는지 쓴다. 할 일이 남았으면 `진행 중`, 사용자가 확인까지 마친 뒤면 `끝남`. `ccs` 는 이 값으로 🟡/🟢 를 정한다.
- 비어 있는 칸은 `- 없음` 으로 둔다. 칸을 지어내지 않는다.
- 비밀값(토큰·비밀번호·키)은 쓰지 않는다.
- 저장한 뒤에는 사용자에게 한 줄로만 알린다: `메모 남김 — <목표> · 상태: <상태>`. 메모 전문을 다시 출력하지 않는다.
- 메모를 쓴 뒤에도 하던 일이 있으면 그대로 이어 간다.
